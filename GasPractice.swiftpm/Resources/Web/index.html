펜슬·마우스로 필기 · 손가락으로 스크롤
필기와 메모는 문항마다 자동 저장됩니다.
연습실 사용 안내

노트 한 권처럼 사용하세요.

  1. 필답형 또는 작업형을 선택하고 회차를 엽니다.
  2. 문제를 읽고 필기 영역에 펜슬이나 마우스로 풉니다. 기본값은 손가락 스크롤이며, 손가락 필기를 켜면 터치로도 쓸 수 있습니다.
  3. 풀이를 확인하고 학습 완료 또는 다시 풀기를 표시합니다.
  4. PC와 아이패드 사이에서 기록을 옮기려면 목록 아래의 백업·가져오기를 사용합니다. 자동 동기화되지는 않습니다.

아이패드: Safari에서 공개 주소를 열고 공유 → 홈 화면에 추가를 이용하세요. 가로 모드에서 더 넓게 필기할 수 있습니다.

이 사이트의 필기·진도는 해당 브라우저에만 보관됩니다. 브라우저 데이터를 삭제하기 전에 백업하세요. 비공개 모드에서는 기록이 유지되지 않을 수 있습니다.

다운로드 ZIP을 풀고 index.html을 열면 PC에서 사용할 수 있습니다. 아이패드에서는 공개 사이트 주소로 접속하세요.
